# Tam Yığın Web Geliştirme Uygulama Projesi

Bu proje, modern **Tam Yığın Web Geliştirme** yeteneklerimi sergilemek üzere tasarlanmış kapsamlı bir uygulamadır. HTML5, CSS3, JavaScript, React.js (Redux, Hooks, Context API ile), Node.js, Express.js ve MongoDB gibi sektörde popüler teknolojileri kullanarak gerçek dünya problemlerine çözümler üreten, duyarlı ve dinamik bir web uygulaması geliştirmeyi amaçlamaktadır.

-----

## Proje Hakkında

Bu proje, çeşitli web geliştirme alanlarındaki bilgi birikimimi ve pratik becerilerimi bir araya getirmektedir. Aldığım eğitim boyunca öğrendiğim teorik bilgileri pratik uygulamalara dönüştürerek, modern web standartlarına uygun, kullanıcı dostu ve ölçeklenebilir bir uygulama ortaya çıkardım.

-----

## Öğrenilen Temel Teknolojiler ve Konular

Bu proje, aşağıdaki temel teknolojiler ve kavramlar üzerine inşa edilmiştir:

### Frontend Geliştirme

  * **HTML5 & CSS3**: Web sayfalarına benzersiz stil ve yapı kazandırmak için en son HTML5 ve CSS3 özelliklerini kullanma.
  * **Bootstrap 4**: Duyarlı ve çekici kullanıcı arayüzleri (UI) oluşturmak için Bootstrap 4'ü baştan sona öğrenme ve uygulama:
      * Bootstrap Grid Sistemi ve tema düzeni oluşturma.
      * Yüksek kaliteli Bootstrap 4 temaları ve UI'ları sıfırdan oluşturma.
  * **Sass**: Kolayca Sass derleme yöntemlerini kullanarak daha verimli CSS yazma.
  * **CSS Grid ve Flexbox**: Esnek ve karmaşık sayfa düzenleri oluşturmak için Grid CSS ve Flexbox özelliklerini etkili bir şekilde kullanma.
  * **Duyarlı Tasarım**: Farklı ekran boyutları ve cihazlar için uyumlu web tasarımları geliştirme.
  * **JavaScript (ES6+)**:
      * DOM manipülasyonu.
      * Fonksiyonlar (Function Declaration vs. Function Expression).
      * Objeler ve metodları.
      * Gelişmiş JavaScript kavramları (Curly-braced, dynamically typed, prototype-based, object-oriented programming).
  * **React.js**:
      * **Temel Kavramlar**: Bileşenler (component), Props, State yönetimi ve Bileşen Yaşam Döngüsü Metodları.
      * **Modern React**: Redux, Hooks ve Context API kullanarak karmaşık durum yönetimi ve bileşenler arası veri akışı sağlama.
      * Yeniden kullanılabilir React bileşenleri oluşturma.
      * Tek Sayfa Uygulamaları (SPA) geliştirme.
  * **Harici API Entegrasyonu**: Gerçek dünya projeleri için harici API'lere bağlanma ve veri alışverişi yapma.
  * **Kullanıcı Kimlik Doğrulama ve Kayıt Sayfaları**: Ortak kullanılan kullanıcı giriş ve kayıt sayfalarını form yapısıyla oluşturma.

### Backend Geliştirme

  * **Node.js & Express.js**:
      * Hızla büyüyen web sunucu teknolojisi Node.js'e derinlemesine dalış ve Node.js'in çalışma prensiplerini anlama.
      * Sunucular oluşturma.
      * Event Emitter, Buffers, Streams ve Pipes gibi temel Node.js kavramlarını anlama ve kullanma.
      * Node.js ile routing yönetimi.
      * Güçlü, sağlam web uygulamaları oluşturma.
  * **MongoDB & Mongoose JS**:
      * En çok kullanılan açık kaynaklı belge tabanlı, NoSQL veritabanı MongoDB'yi öğrenme.
      * MongoDB için en popüler Nesne Veri Modelleme Kütüphanesi Mongoose JS'i kullanma.
      * CRUD (Create, Read, Update, Delete) operasyonları için sorgular yazma.
      * Veritabanı yönetimi için terminal komutlarını anlama.
  * **MERN Stack**: React.js, Express.js, Node.js ve MongoDB'yi bir araya getirerek tam yığın uygulamalar geliştirme:
      * Harika, duyarlı bir açılış sayfası (landing page) oluşturma.
      * Gerçek dünya MERN Stack projeleri ve web uygulamaları geliştirme.

### Test

  * **Mocha**: Node.js için en iyi test framework'ü olan Mocha ile test yazma.
